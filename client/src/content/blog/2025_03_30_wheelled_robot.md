# 复刻桌面轮足机器人，办公桌面的趣味移动搭子！

> **文章摘要**：本文详细介绍了一款基于ESP32的微型轮腿机器人复刻项目。该机器人采用轮式+腿式混合结构，通过FOC算法驱动无刷轮毂电机，支持WiFi远程控制。文章涵盖硬件选型、PCB设计、软件架构及制作流程，适合机器人爱好者学习参考。

---

## 📖 项目介绍

**什么是轮腿机器人？**

轮腿机器人是一种结合了轮式移动和腿式运动优点的混合型机器人。它既能像轮式机器人一样在平坦地面高效移动，又能通过腿部结构调整姿态、跨越障碍，兼具灵活性与稳定性。

**为什么选择这个项目？**

- 🎯 **学习价值高**：涵盖机械设计、电路设计、嵌入式开发、控制算法等多个领域
- 🔧 **制作难度适中**：零件易获取，代码开源，适合DIY入门进阶
- 🎮 **趣味性强**：WiFi遥控、网页操作，可作为桌面玩具或展示作品

## ✨ 功能特点

|      特性       | 描述                        |
| :-------------: | :-------------------------- |
| 🦿 **混合运动** | 轮式+腿式结合，适应多种地形 |
| 📏 **超小体积** | 桌面级尺寸，适合室内环境    |
| 📶 **WiFi控制** | 支持AP热点/STA客户端双模式  |
| 🌐 **Web界面**  | 通过浏览器实时控制机器人    |
| 🔓 **完全开源** | 机械结构、PCB、代码全部开源 |

### 🎮 运动控制

- **自主站立**：点击"Robot go!"按钮后自动站立
- **摇杆控制**：通过虚拟摇杆实时控制前进、后退、转向
- **姿态平衡**：基于IMU实时检测并保持机身平衡
- **腿部联动**：双舵机协调控制，实现腿部伸缩动作

### 🧠 控制算法

- **FOC控制**：磁场定向控制算法，精准驱动无刷轮毂电机
- **SimpleFOC**：基于开源SimpleFOC库，支持速度/位置/力矩控制
- **实时反馈**：AS5600编码器提供高精度角度反馈

### 📡 通信功能

- **WebSocket协议**：低延迟实时双向通信
- **JSON数据格式**：结构化指令传输
- **跨平台支持**：兼容Android、iOS、Windows、macOS、Linux

## 🔧 硬件组成

### 主控系统

|   组件   |  型号/规格   | 说明                 |
| :------: | :----------: | :------------------- |
| 主控芯片 |    ESP32     | 集成WiFi，双核处理器 |
| 电机驱动 | L6234PD013TR | 无刷电机驱动芯片     |
|  编码器  |    AS5600    | I2C接口磁编码器      |
|   IMU    |   MPU6050    | 六轴姿态传感器       |
| 腿部舵机 | 总线舵机 x2  | ID分别为1和2         |

### 电源与连接

|   组件   |    规格     | 说明           |
| :------: | :---------: | :------------- |
| 电池接口 |   XH2.54    | 锂电池供电     |
| 板间连接 | GH1.25 4PIN | 模块间通信连接 |
| PCB数量  |     4块     | 需要打样制作   |

## 💻 软件架构

### 技术栈

```
开发环境: Arduino IDE
编程语言: C/C++ (C++ 56.8%, C 43.2%)
电机控制: SimpleFOC库
通信协议: WebSocket
PCB设计: 立创EDA (LCEDA)
```

### WiFi配置

|   模式   | 说明                     |
| :------: | :----------------------- |
|  AP模式  | 机器人作为热点，手机直连 |
| STA模式  | 机器人连接家庭WiFi       |
| 控制地址 | `192.168.1.11`           |

## 🛠️ 制作流程

### 1. 机械部分

- 3D打印结构件
- CNC加工金属零件
- 亚克力板切割

### 2. 电子部分

- PCB打样（4块板子）
- 元器件焊接
- 模块连接测试

### 3. 软件部分

- 安装Arduino IDE
- 导入SimpleFOC库
- 烧录程序到ESP32
