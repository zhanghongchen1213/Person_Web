# 魔法不够赛博来凑！DIY 赛博魔杖，挥一下直接解锁未来魔法！

> **文章摘要**：本文介绍如何使用全志 V851s 开发板、BMI088 传感器和 Keras 机器学习框架，打造一根能识别手势的赛博魔杖。挥动魔杖即可控制智能设备，让科幻电影中的魔法场景走进现实！


## 前言

还记得《哈利·波特》里挥动魔杖施展魔法的场景吗？虽然我们没有霍格沃茨的入学通知书，但可以用技术实现属于自己的"赛博魔法"！

本项目通过 **惯性传感器 + 机器学习** 的方案，让一根普通的"棍子"变成能识别手势的智能魔杖。挥出不同的轨迹，就能触发不同的"魔法效果"——比如开关灯、控制音乐、甚至操控智能家居。

**核心技术栈：**
- 硬件平台：全志 V851s + BMI088
- 机器学习：Keras + TensorFlow Lite
- 通信方式：蓝牙控制

## 技术原理

### 整体工作流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  挥动魔杖   │ -> │  采集数据   │ -> │  模型推理   │ -> │  执行动作   │
│  (手势输入) │    │  (BMI088)   │    │  (TFLite)   │    │  (蓝牙控制) │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 为什么选择 BMI088？

BMI088 是博世推出的高性能六轴惯性测量单元，包含：
- **三轴加速度计**：测量线性加速度
- **三轴陀螺仪**：测量角速度

相比常见的 MPU6050，BMI088 具有更低的噪声和更高的精度，非常适合手势识别场景。

### 机器学习方案

项目采用 **时序分类** 的方式识别手势：

1. **数据采集**：每次挥动采集 2 秒数据（128 个采样点 × 3 轴）
2. **特征提取**：神经网络自动学习时序特征
3. **分类输出**：输出各手势的概率，取最大值作为识别结果

## 软件架构

项目包含三个主要模块：

### 1. 数据采集模块

- 运行在 V851s 开发板上
- 通过 BMI088 传感器采集加速度和陀螺仪数据
- 采样频率 64Hz，单次采集 2 秒（128 个数据点）
- 数据保存为 CSV 格式（128 行 × 3 列）

### 2. 模型训练模块

- 基于 Keras 框架的神经网络模型
- 读取按文件夹分类的手势数据集
- 支持导出 `.h5` 和 `.tflite` 格式

### 3. 手势识别模块

- 部署 TFLite 模型进行实时推理
- 支持蓝牙控制外部设备
- 串口通信数据传输

## 使用说明

### 数据采集

1. 初始化目录结构：

```bash
source ./dir.sh
```

2. 初始化陀螺仪（上电后必须执行）：

```bash
./bmiHARAPP ginit
```

3. 采集手势数据：

```bash
./bmiHARAPP <手势标签> [起始编号]
```

示例：

```bash
./bmiHARAPP A      # 采集手势 A，保存到 ./HarData/A/
./bmiHARAPP 3 7    # 采集手势 3，从编号 007 开始
```

> 按下按键开始采集，LED 亮起；松开按键或 2 秒后自动停止

### 手势识别

1. 初始化陀螺仪：

```bash
./wandAPP ginit
```

2. 运行手势识别：

```bash
./wandAPP
```

### 模型训练

使用 Jupyter Notebook (`wand.ipynb`) 进行模型训练：

1. 将采集的数据按手势标签放入 `rawData` 文件夹
2. 运行 notebook 进行训练
3. 导出 `.tflite` 模型用于嵌入式部署
