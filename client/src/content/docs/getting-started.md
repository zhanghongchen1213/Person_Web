# 快速开始

将你的 Markdown 文档放到 `client/src/content` 目录下即可。

## Frontmatter

每个文件顶部使用 `---` 包裹元数据，例如 `title`、`slug`、`type`。

## 发布

提交到仓库后执行构建，产物上传到 OBS 并通过 CDN 分发。
